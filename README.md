# Atelier Paint Co. — public portfolio demo

A static, public showcase of a fictional interior painting business website. This copy was prepared from the user's local full-stack project for portfolio viewing. It is not a real painting company.

The demo includes responsive pages for services, room inspiration, about, and contact, plus an interactive room-by-room preliminary estimate. Contact and quote submissions, admin pages, and database features are intentionally disabled in this public version; no visitor details are collected.

To rebuild locally, run `npm ci` and `npm run build`. The static output is in `out/`.
